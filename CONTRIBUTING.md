# 🤝 Contributing to Drive-Nova

> Developed by Syed Muhammad Tayyab

Thanks for wanting to improve Drive-Nova! 🚗💨

1. **Fork** the repo and create a branch: `git checkout -b feat/my-feature`
2. Keep the project **dependency-free** (HTML + Tailwind CDN only) unless discussed first.
3. Put new images in `assets/images/` using `kebab-case` names.
4. Test at mobile (375px), tablet (768px) and desktop (1280px+) widths.
5. Commit with clear messages: `feat: add gallery section`, `fix: navbar overflow on mobile`.
6. Open a **Pull Request** and fill in the template.

## 🧭 Code style
- 2-space indentation, semantic HTML, descriptive `alt` text on every image.
- Prefer Tailwind utility classes; avoid inline `style=""`.

## 🐞 Reporting bugs
Use the **Bug report** issue template and include browser, device and screenshots.
