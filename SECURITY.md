# 🔐 Security Policy

> Developed by Syed Muhammad Tayyab

Drive-Nova is a static front-end page with no backend, forms or user data.
If you still find a security concern (for example in a third-party CDN reference), please open a
private report through **GitHub → Security → Report a vulnerability**, or contact the maintainer via
[GitHub](https://github.com/Syed-Muhammad-Tayyab).
