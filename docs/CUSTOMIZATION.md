# 🎨 Customization Guide

> Developed by Syed Muhammad Tayyab

| I want to… | Edit this |
|---|---|
| Change the brand name | `<span>` next to the logo inside `<nav>` |
| Swap the hero car | Replace `assets/images/hero-porsche-mission-e.png` (transparent PNG works best) |
| Change the accent colour | Search `#fc3f31` and `red-500` in `index.html` |
| Update stats | The four `<h2>` numbers in the hero icons block |
| Replace product details | Content section: title, description, price, colours |
| Change the favicon | Replace `assets/images/favicon.png` |
